# Calamus · гостевой каталог

Готовые Windows-приложения Calamus Claro. В этом репозитории публикуются только выбранные программы и чистый Calamus Launcher — без личных токенов, подписок Proxy и пользовательских данных.

**Скачать Launcher:** [последний релиз](https://github.com/CalamusClaro/Calamus-Launcher-Guest/releases/latest).

При первом запуске выбери **Гость** и вставь ссылку:

`https://github.com/CalamusClaro/Calamus-Launcher-Guest`

Доступны Emoji Studio, Calamus Capture, SlayerLog, Calamus Whisper и Calamus ProxyClient. Остальные приложения автора в гостевой каталог не входят.

Whisper устанавливает необходимые локальные компоненты и модель при первом использовании. ProxyClient требует собственной подписки/серверов пользователя и ядра sing-box; существующая кнопка установки скачивает ядро из официального источника. Авторские подключения не предоставляются.

Программы экспериментальные. Скачивание, установка и обновление выполняются через Launcher. Пользовательские данные хранятся отдельно от файлов программ.
